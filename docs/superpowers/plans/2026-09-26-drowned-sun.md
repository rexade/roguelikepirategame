# The Drowned Sun Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. This plan is executed inline by the Lead (the owner asked for no check-ins); art generators are specified by parameters because their exact code is iterated against playground screenshots.

**Goal:** Give the game a trademark theme (The Drowned Sun) and a fixed, large, zoned world (starting lagoon -> Broken Causeway -> Colossus Deeps) without breaking the campaign rules, saves or tests.

**Architecture:** Procedural faceted art kit (runtime `MeshBuilder` + editor generators) -> standalone playground scene with a screenshot tour -> new region content assets and world authoring on the large map -> presentation systems (zone atmosphere, camera framings, beacons, lore) wired by `GameDirector` -> UI reskin with OFL fonts and generated parchment textures. Rules stay engine-free; everything visual is presentation (INV-14).

**Tech Stack:** Unity 6000.3.24f1, HDRP 17.3 (WaterSurface, Volume: GradientSky, Fog, Bloom, ColorAdjustments, WhiteBalance), UI Toolkit, NUnit (EditMode/PlayMode), batch runner `tools/RunUnity.ps1`, `dotnet build tools/FastCheck/All.csproj`.

**Spec:** `docs/superpowers/specs/2026-09-26-drowned-sun-design.md`

## Global Constraints

- Keep IDs that live in campaign saves: hubs `home-harbor`, `saltmarsh-harbor`, `stormwatch-harbor`; resources `wood`, `iron`; upgrades, tracks, equipment, unlocks unchanged.
- New region IDs: `gilded-shallows`, `broken-causeway`, `colossus-deeps`; entity definition `relic` replaces `barrel` in production (`barrel` stays valid for the T06 fixture).
- Rules (`PirateGame.Core`, `PirateGame.Persistence`) remain `noEngineReferences`; no presentation value feeds rules (INV-14).
- T06 fixture content (`FirstRegion.asset`, `Salvage.unity`, `FirstRegion.prefab`) is not modified; production stops mutating it.
- Only OFL fonts (Cinzel, EB Garamond) are downloaded; all other art is generated by code.
- D02 targets (median <= 16.7 ms, p95 <= 20 ms on the reference PC) still hold.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Unity must be closed for batch runs; run one Unity job at a time.

### Task 1: Faceted mesh kit (runtime)

**Files:** Create `Assets/_Game/Art/DrownedSun/Kit/PirateGame.ArtKit.asmdef` (no references, autoReferenced), `MeshBuilder.cs`, `Shapes.cs`; test `Assets/_Game/Tests/T12/DrownedSunTests.cs` + `PirateGame.T12.Tests.asmdef` (EditMode, refs ArtKit, WorldPresentation, Persistence, Core, FirstRegion, Composition).

**Interfaces (produced):**
```csharp
namespace PirateGame.Art {
  public sealed class MeshBuilder {
    public int TriangleCount { get; }
    public MeshBuilder Triangle(Vector3 a, Vector3 b, Vector3 c);          // clockwise seen from the front (Unity winding)
    public MeshBuilder Quad(Vector3 a, Vector3 b, Vector3 c, Vector3 d);   // a-b-c-d clockwise
    public MeshBuilder Polygon(IReadOnlyList<Vector3> ring);               // convex fan, clockwise
    public MeshBuilder Append(MeshBuilder other, Matrix4x4 transform);
    public MeshBuilder Append(MeshBuilder other, Vector3 position, Quaternion rotation, Vector3 scale);
    public Mesh Build(string name);                                        // unshared vertices, flat normals, planar UV (xz), bounds
  }
  public static class Shapes {
    public static MeshBuilder Prism(IReadOnlyList<Vector2> outline, float bottom, float top, float chamfer = 0, bool capBottom = false);
    public static MeshBuilder Box(Vector3 size, float chamfer = 0);        // centred
    public static MeshBuilder Lathe(IReadOnlyList<Vector2> profile /*(radius,y) bottom->top*/, int sides, float phase = 0, bool capTop = true);
    public static MeshBuilder Disc(float radius, float thickness, int sides, int rays = 0, float rayLength = 0);
    public static MeshBuilder Heightfield(Rect area, float cell, Func<float, float, float> height, float dropBelow);
    public static Vector2[] Ring(int sides, float rx, float rz, int seed = 0, float jitter = 0);
  }
}
```

- [ ] Write EditMode tests: a chamfered box has 6 + 12 + 8 faces worth of triangles and every normal equals its face normal (no smoothing); a prism of an 8-gon is closed (every edge shared by exactly two triangles); a heightfield drops cells whose four corners are below `dropBelow`; `Build` produces bounds that contain all vertices and normals of unit length.
- [ ] Run `./tools/RunUnity.ps1 -Mode EditMode -Name t12-edit -Assemblies 'PirateGame.T12.Tests'` -> FAIL (types missing).
- [ ] Implement `MeshBuilder` (lists of vertices/triangles; each triangle gets its own three vertices; `Build` sets `indexFormat = UInt32` when > 65k vertices, calls `RecalculateNormals` (flat because unshared), `RecalculateBounds`, UV = (x, z) / 4).
- [ ] Implement `Shapes` (chamfer = top ring inset + bevel ring; lathe with per-ring radius, optional cap; disc with triangular rays; heightfield two triangles per cell with the diagonal alternating; `Ring` jitters radius deterministically with `System.Random(seed)`).
- [ ] Run tests -> PASS. Commit "Drowned Sun kit: faceted mesh builder and shapes".

```csharp
  [CreateAssetMenu] public sealed class AtmosphereProfile : ScriptableObject {
    public string mood; public float anchorZ;

    public float saturation, contrast, temperature, bloom, vignette; public Color filter;

    public Light sun; public Volume volume; public WaterSurface ocean; public AtmosphereProfile[] profiles; public Transform follow; public float response = 0.6f;

    public Transform target; public float Threat { get; set; } /*0..1*/ public float Near { get; set; } /*0..1*/
    public Vector3? HarborFocus { get; set; } public Vector3? FocusOverride { get; set; }
    public static Pose Frame(Vector3 ship, float yaw, float pitch, float distance, float lookAhead);  // pure, tested
    public void Snap();
  }
}
```

- [ ] Tests: `Evaluate` returns the first profile below its anchor, the last above, the exact midpoint blend halfway (smoothstep 0.5); `Frame` at pitch 60 and distance 56.6 reproduces the D05 offset (0, 49, -28.3) for yaw 0; framing at pitch 28 puts the camera behind the ship along -heading.
